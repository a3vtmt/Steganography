# Steganography
Консольная утилита, которая позволяет прятать текст в изображения формата .png путем замены младшего бита (LBS) в пикселях картинки.

В данной реализации было принято решение не использовать стандартные ASCII коды символов, потому что они содержат числовые значения от 1 до 127 (расширенная версия включает до 255), а это 7 бит информации. Для сжатия данных была использованная простая, но эффективная схема с массивом допустимых символов, она ограничивает разнообразие сообщений, но позволяет записывать на 2 бита данных меньше, что составляет ~29% экономии пространства. Можно добиться большего процента сжатия, но только на большом количестве информации, что небыло в интересах данной реализации.

Для работы с изображениями была выбрана простая и легковесная библиотека stb_image от автора Sean Barrett (stb-master), которая используется для загрузки изображений и распространяется по свободной лицензии _Public Domain / MIT_.

Функция read принимает на вход массив пикслей (data), а так же высоту (h), ширину (w) и каналы изображения (c), после чего в случае нахождения сообщения возвращает его или пустую строку.

Функция write принимает на вход текст сообщения (text), массив пикселей (data), а так же высоту (h), ширину (w) и каналы изображения (c), записывает его в пиксли и завершает свою работу.
